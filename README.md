# Projeto de Álgebra Linear Algorítmica — IC/UFRJ

Este projeto reúne a construção de um site contendo os laboratórios e materiais da disciplina **Álgebra Linear Algorítmica (ICP115)** do Instituto de Computação da UFRJ.

A disciplina integra teoria e prática, com atividades em laboratório onde os alunos aplicam conceitos de álgebra linear em problemas computacionais, incluindo temas como sistemas lineares, transformações lineares, autovalores e ortogonalização.

O projeto surgiu a partir de uma reformulação curricular que introduziu uma abordagem mais aplicada à disciplina, alinhada com áreas atuais como ciência de dados e inteligência artificial.
